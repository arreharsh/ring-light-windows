# Ring Light for Windows 💡

A Windows desktop application that brings Mac's ring light feature to Windows. Enhance your video calls and meetings with professional lighting right from your screen!

**Platform:** Windows Desktop App

## 🌟 Overview

Ring Light for Windows is an Electron-based desktop application that replicates macOS's popular ring light feature for Windows users. It provides a simple, effective way to improve lighting during video calls, online meetings, and content creation.

## ✨ Features

- 🔦 **Professional Ring Light** - Screen-based lighting for better video quality
- 💻 **Windows Native** - Built specifically for Windows using Electron
- 🎨 **Simple & Clean UI** - Easy to use interface with HTML, CSS, and JavaScript
- 🚀 **Lightweight** - Minimal resource usage
- ⚙️ **Customizable** - Adjust brightness and settings as needed

## 🛠️ Installation

### Prerequisites
- Windows OS (Windows 10 or later recommended)
- Node.js and npm installed

### Setup Steps

```bash
# Clone the repository
git clone https://github.com/arreharsh/ring-light-windows.git

# Navigate to project directory
cd ring-light-windows

# Install dependencies
npm install

# Run the application
npm start
```

## 📦 Building the App

```bash
# Build for Windows
npm run build
```

## 📖 Usage

1. Launch the Ring Light application
2. Adjust the brightness and size as needed
3. Position the ring light on your screen
4. Start your video call or meeting
5. Enjoy professional lighting!
