# Ring Light for Windows 💡

A Windows desktop application that brings Mac's ring light feature to Windows. Perfect for video calls, meetings, and content creation.

**Status:** Live  
**Chrome Extension:** Coming Soon 🚀

## 🌟 Overview

Ring Light for Windows is an Electron-based desktop application that replicates macOS's popular ring light feature for Windows users. Enhance your video call appearance with professional lighting directly from your Windows PC.

## ✨ Features

- 💡 **Professional Ring Light** - Adjustable brightness and color temperature
- 🖥️ **Native Windows App** - Built with Electron for seamless performance
- 📹 **Video Call Compatible** - Works with Zoom, Teams, Meet, and all video calling apps
- 🎨 **Customizable Settings** - Adjust brightness, size, and position
- 🪶 **Lightweight** - Simple HTML, CSS, and JavaScript implementation
- 🔄 **Always on Top** - Stays visible during your meetings

## 🚀 Upcoming Features

- 🌐 **Chrome Extension** - Use ring light directly in your browser
- 📱 **Cross-Platform Support** - Support for all major meeting platforms
- 🎛️ **Advanced Controls** - More customization options

## 🛠️ Tech Stack

- **Framework:** Electron
- **Frontend:** HTML, CSS, JavaScript
- **Platform:** Windows

## 📦 Installation

### Download (Recommended)
1. Go to [Releases](https://github.com/arreharsh/ring-light-windows/releases)
2. Download the latest `.exe` installer
3. Run the installer and follow the setup wizard
4. Launch Ring Light from your desktop or start menu

### Build from Source

```bash
# Clone the repository
git clone https://github.com/arreharsh/ring-light-windows.git

# Navigate to project directory
cd ring-light-windows

# Install dependencies
npm install

# Run the application
npm start

# Build for production
npm run build
```

## 🎯 Usage

1. Launch the Ring Light application
2. Position the ring light window on your screen
3. Adjust brightness and settings as needed
4. Keep it on top during your video calls
5. Close when done

### Best Practices
- Position the light at eye level for best results
- Adjust brightness based on your ambient lighting
- Use with your favorite video calling app (Zoom, Teams, Google Meet, etc.)

- **OS:** Windows 10/11
