# Ring Light for Windows 💡

A Windows desktop application that brings macOS-style ring light functionality to your PC. Perfect for video calls, streaming, and content creation!

## 🌟 Overview

Ring Light for Windows is an Electron-based desktop application that replicates the popular ring light feature from macOS, making it available for Windows users. It provides a virtual ring light overlay that enhances your video call appearance and improves lighting conditions for any camera-based activity.

## ✨ Features

- 🔆 **Virtual Ring Light** - Professional-looking ring light effect on Windows
- 💻 **Lightweight Application** - Built with Electron for smooth performance
- 🎨 **Customizable** - Adjust brightness and appearance to your needs
- 🖥️ **Easy to Use** - Simple and intuitive interface
- 🎯 **macOS Replica** - Brings the beloved macOS feature to Windows
- 📹 **Perfect for Video Calls** - Enhance your appearance in meetings and calls

## 📦 Installation

### Download & Install

1. Go to the [Releases](https://github.com/arreharsh/ring-light-windows/releases) page
2. Download the latest `.exe` installer for Windows
3. Run the installer and follow the installation steps
4. Launch Ring Light for Windows from your Start Menu

### Build from Source

```bash
# Clone the repository
git clone https://github.com/arreharsh/ring-light-windows.git

# Navigate to project directory
cd ring-light-windows

# Install dependencies
npm install

# Run the application in development mode
npm start

# Build the application
npm run build
```

## 🎮 Usage

1. Launch the Ring Light for Windows application
2. Position the ring light overlay on your screen
3. Adjust the brightness and size as needed
4. Start your video call or recording
5. Enjoy professional lighting for your camera!

## 💡 Why Ring Light for Windows?

Good lighting is crucial for video calls, streaming, and content creation. While macOS has a built-in ring light feature, Windows users have been left out. This application bridges that gap by providing:

- Professional-looking lighting without expensive hardware
- Software-based solution that works with any camera
- Customizable lighting to match your environment
- Free and open-source alternative to physical ring lights
